# OfficeTech Pro — разделённый Telegram-бот

В этой версии бот разделяет клиентов и администратора.

## Как это работает

- Клиент открывает бота и видит клиентское меню.
- Клиент отправляет заявку.
- Клиент получает только подтверждение.
- Админ получает полную заявку в Telegram.

## Переменные Vercel

Минимально нужны:

TELEGRAM_BOT_TOKEN
ADMIN_TELEGRAM_ID
PUBLIC_URL

Дополнительно можно добавить:

ADMIN_CHAT_ID

Если ADMIN_CHAT_ID не указан, заявки идут в ADMIN_TELEGRAM_ID.

## Лучший вариант для заявок

1. Создать Telegram-группу: `OfficeTech заявки`.
2. Добавить туда своего бота.
3. Узнать ID группы.
4. В Vercel добавить переменную ADMIN_CHAT_ID.
5. Сделать Redeploy.
6. Открыть `/api/set-webhook`.

## Важно

Vercel не хранит историю заявок сам по себе.  
Чтобы была полноценная админ-панель со списком заявок, нужна база данных: Supabase, Firebase, Google Sheets или PostgreSQL.
